# Test bout en bout — Atlas présente le site

## Règles d'exécution

- Le préflight est relancé avant chaque run.
- Un run comprend : assets LTX, contrôle visuel, préparation du plan, génération vidéo LTX-2.5, extraction de captures et contrôle du rendu.
- Une correction peut relancer le run automatiquement, avec un maximum de cinq runs.
- Un run non conforme est conservé et décrit avant la correction suivante.
- Aucun modèle, média généré ou journal lourd n'est versionné.

## Critères de conformité

1. Atlas conserve une identité stable entre les vues.
2. La tenue est jaune et cohérente.
3. La plaquette reste devant Atlas et n'apparaît jamais derrière son dos.
4. Le décor reste fixe ; Atlas arrive uniquement depuis la droite puis s'arrête face caméra.
5. Le dialogue et la présentation du site correspondent au script validé.
6. Le zoom final montre la version claire du site et l'adresse exacte.
